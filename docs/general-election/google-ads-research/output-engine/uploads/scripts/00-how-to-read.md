# How to read these scripts

- **No names on screen.** Characters are labelled by role: CONFIDENT (confident friend), SOURCE (source friend), ORGANIZER, LITERAL (literal friend). Sheets are in `characters/<slug>/`. Nobody says a name in dialogue, captions or titles.
- **No catchphrases.** Lines are written to sound overheard.
- **Slice-of-life scenes start mid-conversation.** No hello, no setup line to camera. People talk over each other, trail off and react. Lines marked `(overlapping)` start before the previous line ends. Treat the wording as a guide: actors or voice direction may loosen it, but keep every factual line exact.
- **Creator-format scenes** (05 commute vlog, 08 get-ready-with-me) are the only ones where someone speaks to camera, because that is what the format is.
- **Timings** are targets for a 9:16 cut of 20–35 seconds.
- **Bracketed fields** like `[provider]` must be filled from a current official source before any export (see each script's fact card).
