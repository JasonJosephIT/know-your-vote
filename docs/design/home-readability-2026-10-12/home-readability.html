Home page: sample ballot links and an easier scroll

The founder asked for sample ballots and other helpful resources to be easier to find, and for the page to feel more scroll-friendly, especially on phones. This page shows the reconciled plan with before/after mockups built from the site's real tokens, copy and section order. The written spec is home-readability.md beside this file.

The plan. A new block, “Sample ballot and how to vote”, sits 12px under the key dates and links only to the county Supervisors of Elections' own pages and the Florida Division of Elections: your sample ballot, where to vote on Election Day, early voting, and the mail ballot (which switches from “Request” to “Return” on October 23). A saved district shows that county's four links; otherwise five closed rows let the voter pick a county. It stores nothing. It takes the slot of the three count tiles, which become an “On this page” jump list. PR A also tightens the top of the phone page, drops repeated copy, shows the 4 newest stories on phones and ends the desktop news column's inner scroll. PR B (frozen ballot files, all or nothing, merge by Fri Oct 16) puts one candidate name per line, says the date once, makes “Amendment N” the heading with the official title quoted underneath, and folds the judges' court links into a disclosure. PR C (optional) stops the bars being fixed on short screens.

      Neutrality and accessibility checks

      Neutrality

      • Official sources only: the four Supervisors' own pages and the Division of Elections. No vendor tools, no Vote411, no Ballotpedia on the home page.
      • Every county the same: same four tiles, labels, order and style; all closed; the only preselection is the visitor's own saved county. A verify script enforces all-or-none.
      • County facts are the county's: each “Asks for” line is that county's form. The early-voting window shows for all four counties or none. No hours printed (Orange 8–8, the others 7–7).
      • Dates stated, never counted; from verified rows only.
      • Every candidate the same: one line each, ballot order, same size and colour, every name printed, nothing truncated or collapsed. The jump list names sections, never a race.
      • Amendment titles verbatim in ALL CAPS; only size and position change.
      • Judges: collapsed identically everywhere; the visible sentence says they're on the ballot and not covered. The home page still passes no county.
      • News: the phone cap is time only, the same for every region filter. A lopsided 4 gets the news-fairness §2 check, then is shown, never padded or trimmed. The Jolly campaign-stop row is a tagging gap to fix in the pipeline.
      • No new storage: no cookie, localStorage key or URL parameter.

      Accessibility (WCAG 2.2 AA)

      • Targets: tiles and county rows ≥48px, jump chips 40px, judges summary 32px, footer links 24px.
      • Text: nothing a voter must read below 14px; key dates, banner links and row status rise from 13px.
      • Contrast: primary-hover on primary-muted ≈6.8:1; ink on primary-muted ≈12.9:1.
      • Headings: h1 → h2 Sample ballot… → h2 On this page → h2 Statewide races → h3 offices → h2 Ballot questions → h3 Amendment N → h3 Judges (outside the disclosure) → h2 House → h2 News → h2 What this guide covers.
      • Links: SVG glyphs (the Inter subset lacks ↗ ↓ ›); new-tab links name their county in sr-only text.
      • Disclosures: native details/summary; keyboard and no-JS work; every summary names its county or subject.
      • Anchors: no scroll-mt; the root scroll-padding clears the bars.
      • Reflow: single column below sm, no fixed widths, no horizontal scroll at 320px.
      • PR C: bars static at ≤500px tall, freeing 26–46% of the screen at 200–400% zoom.

      How the two judges' specs were reconciled

      Both judges built on Design 2 with Design 1's resources block. Where they differed, the call went by neutrality first, then readability evidence, then build risk.

      Not doing
      • No address field in this block and no embedded county tool (the House step's field already takes an address and keeps only the district; the county tools load third-party scripts).
      • No vendor deep links: VoterFocus, electionsfl.org and OmniBallot addresses change between elections.
      • No sticky sub-nav (content-to-chrome ≈5.9:1 → ≈4:1) and no hide-on-scroll top bar.
      • No collapsing or truncating of races or amendments.
      • No county passed through SharedBallot (deliberate; pinned by verify-judicial-retention).
      • No CSS :has() radio pills, no “Vote” nav item, no globals.css token changes, no SUPERVISOR_LIST_URL change.
      • No new art: the palm sticker retires with the tiles; the sun, seated reader, cat and magnifier stay as they are.
