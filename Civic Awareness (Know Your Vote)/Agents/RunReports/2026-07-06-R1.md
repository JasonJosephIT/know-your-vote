## 2. Second blocker (unchanged from 2026-07-03): candidate roster is fixture data, not real people

Confirmed again from the live schema today:

```sql
SELECT candidate_id, legal_name, official_site FROM candidate
WHERE candidate_id IN ('demo-cand-boone','demo-cand-webb','demo-cand-reyes');
```
```json
[{"candidate_id":"demo-cand-boone","legal_name":"Gregory Boone","official_site":"https://example.org/demo/boone"},
 {"candidate_id":"demo-cand-reyes","legal_name":"Daniel Reyes","official_site":"https://example.org/demo/reyes"},
 {"candidate_id":"demo-cand-webb","legal_name":"Marcus Webb","official_site":"https://example.org/demo/webb"}]
```
```sql
SELECT source_id, publisher, url FROM source LIMIT 5;
```
```json
[{"source_id":"demo-src-boone-self","publisher":"Demo Fixture (Candidate Campaign Site)","url":"https://example.org/demo/boone/platform"}, ...]
```
All `candidate_id` values are `demo-cand-*`, all `official_site` values point at
`example.org/demo/...`, and `source.publisher` values are literally labeled
`"Demo Fixture (...)"`. Confirmed also via `grep` against
`scripts/build-demo-seed.mjs` in the repo: e.g. `demo-cand-mora` / "Cecilia
Mora" is generated fixture data for the "Commissioner of Agriculture of
Florida" race, not a scraped real candidate.

**Independent spot-checks this run** (three different candidates than the
2026-07-03 report's single check, spanning three different races/parties, to
avoid just repeating the prior conclusion unverified):

| Candidate (fixture) | Race | WebSearch query | Real candidates found instead |
|---|---|---|---|
| Marcus Webb (DEM) | demo-fl-house-15 | `"Marcus Webb" Florida congressional candidate District 15 2026` | Jose Engell, Darren McAuley, Kimberly Overman, Robert People (DEM primary); Laurel Lee (REP, incumbent) — no "Marcus Webb" anywhere |
| Priscilla Chen (DEM) | demo-fl-us-senate | `"Priscilla Chen" Florida U.S. Senate candidate 2026` | Alexander Vindman, Angie Nixon among others — no "Priscilla Chen" anywhere |
| Elena Vargas (DEM) | demo-fl-attorney-general | `"Elena Vargas" Florida Attorney General candidate 2026` | Jim Lewis, Jose Javier Rodriguez (DEM primary); James Uthmeier (incumbent), Steven S. Leskovich (REP primary) — no "Elena Vargas" anywhere |

All three searches returned zero hits for the fixture name and surfaced an
entirely different, real candidate field for the same office. This
independently reconfirms the 2026-07-03 finding: the candidate roster behind
all 8 published races is synthetic fixture data, not real 2026 Florida
candidates. Per the identity-certainty rule ("a search that finds a person
with a similar name is NOT a match"), and since these searches found no
matching name at all (not even a near-miss), there is no candidate identity to
attach real news to for any of the 26.
