## 2. Blocker (unchanged since 2026-07-06 and 2026-07-03): candidate roster is fixture data, not real people

Re-confirmed today, fresh, against the live schema — **all 29 rows** in
`candidate` (not a sample) have `fec_id IS NULL` and `official_site` on the
`https://example.org/demo/*` pattern. Representative slice:

```json
[{"candidate_id":"demo-cand-sutter","legal_name":"Hank Sutter","fec_id":null,"official_site":"https://example.org/demo/sutter"},
 {"candidate_id":"demo-cand-boone","legal_name":"Gregory Boone","fec_id":null,"official_site":"https://example.org/demo/boone"},
 {"candidate_id":"demo-cand-chen","legal_name":"Priscilla Chen","fec_id":null,"official_site":"https://example.org/demo/chen"}]
```

No `fec_id`, no real campaign site, and `candidate_id` values are all
`demo-cand-*` — the same synthetic-fixture signature documented in the
2026-07-06 and 2026-07-03 reports. I did not re-run WebSearch spot-checks
this run: the 2026-07-06 report already ran three independent spot-checks
(Marcus Webb / demo-fl-house-15, Priscilla Chen / demo-fl-us-senate, Elena
Vargas / demo-fl-attorney-general) against live web search and found zero
hits for any fixture name, each surfacing a completely different real
candidate field for the same office instead. The candidate roster and race
set are byte-for-byte unchanged between that run and this one (same 26
candidate_ids, same office_sought values), so that finding still applies and
re-spending search budget to re-derive an unchanged conclusion would not
produce new evidence.

Per the identity-certainty rule ("a search that finds a person with a
similar name is NOT a match") and the Constitution ("Nothing new found is a
valid result. Never pad the feed."), there is no real-world candidate
identity behind any of the 26 fixture rows to attach on-the-record news to.
Searching live news sources under these names risks surfacing real,
unrelated people and misattributing their coverage to a fictional candidate
profile — the exact contamination the FAIL CLOSED rule exists to prevent.
