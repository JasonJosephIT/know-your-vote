## 2. Root finding — all official sites are reserved placeholders

Every one of the 26 candidates has an `official_site` of the form:

```
https://example.org/demo/<slug>
```

`example.org` is IANA's **reserved placeholder domain (RFC 2606)** — it is
not, and cannot be, a real campaign website. These are seed/fixture values,
not live candidate sites.

**Empirical confirmation (not assumed):** fetched a representative URL —

- `https://example.org/demo/kowalski` → **HTTP 404 Not Found**.

Since all 26 candidates share the identical host (`example.org`) and path
scheme (`/demo/<slug>`), this single live fetch establishes the whole batch
as non-live placeholder data. No candidate has a live contact page from
which source-backed contact facts could be drawn.

`fec_id` is NULL for all 26, so there is no FEC filing fallback either
(and even if present, contact facts come only from the candidate's own
official site per the Constitution).
