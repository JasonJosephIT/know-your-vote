Verdict badge

The full fact-check scale. The verdict color drives only the badge’s dot and label — never a filled background — so meaning survives for colorblind readers and never shouts.

Accurate

Checks out fully against the primary source.

Mostly accurate

Largely holds up, with a minor caveat.

Mixed

Part holds up, part does not.

Mostly inaccurate

Largely does not hold up, with a small true element.

Inaccurate

Does not hold up against the primary source.

Unverifiable

No primary source available to check it against.

Never set the verdict color as a background. The neutral surface-muted fill stays constant across all six; only the dot and text carry the scale.
